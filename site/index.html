Sources, filters & calculation details

Source snapshot

The 108 scores are preserved exactly from the nine supplied URLs. Matches use the reviewed catalog from October 28, 2026. All nine people and their combinations use the same version; original PDFs retain their historical results. The supplied PDFs preserve original descriptions, page-by-page text, figures, books, and timelines or values in the report section. Their rounded results are kept separate from the catalog’s recomputed group matches.

Shared compatibility

For every candidate, take the lowest individual compatibility among the selected people. Rank that minimum highest first. Ties use the median individual score, then the mean, then the name. Each card shows all selected individual scores.

Median-profile mode scores the synthetic vector of selected axis medians. It is a different question. The minimum-score filter still requires every selected person to pass.

All 511 nonempty selections have been computed against the full source catalogs. The page retains the top 24 matches per category and method, eight field winners and 12 books. Search operates on those retained matches.

Original recommendation filters

Both match methods honor the original recommendation filter of every selected person. Osmar’s, Miguel’s, Jucimar’s and Lucca’s links specify Catholic; Julia’s specifies Protestant; the other links specify none. The source’s exclusion and exclusivity rules are retained. This describes a filter, not an inferred religious identity.

The compass is an illustrative projection. Matching uses the full 12-axis scoring formula: 42% per-axis similarity, 33% direction, 18% intensity, 7% worst-axis agreement. Matches are not probabilities or endorsements.
